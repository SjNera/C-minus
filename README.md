# C-Minus: From C to Python

A source-to-source compiler that translates a subset of C into runnable Python.

## Setup
    python -m venv .venv
    source .venv/bin/activate        # Windows: .venv\Scripts\activate
    pip install -e ".[dev]"
    cminus --version
    pytest

See the full project README for module ownership and contracts.
